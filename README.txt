سوقي - النسخة التجريبية الأولى (MVP)
=====================================
الملفات:
- index.html: التطبيق وواجهة السوق والمنطق المحلي.
- manifest.json: تعريف التطبيق للتثبيت كـ PWA.
- sw.js: تخزين ملفات الواجهة للعمل دون اتصال بعد أول زيارة على استضافة HTTPS.

تشغيل سريع:
1) فك ضغط souqi_yemen_mvp.zip.
2) افتح index.html في متصفح لمعاينة الواجهة محليًا. قد لا تعمل خصائص PWA والتخزين دون اتصال بالكامل عند فتح file://.
3) لتجربة التثبيت والعمل دون اتصال، ارفع الملفات إلى استضافة HTTPS ثابتة (مثل GitHub Pages) ثم افتح الرابط في Chrome على Android واستخدم قائمة المتصفح > إضافة إلى الشاشة الرئيسية / تثبيت التطبيق إذا ظهر الخيار.

مهم:
- كل المنتجات الأولية بيانات وهمية للتجربة، والأسعار ليست عروضًا حقيقية.
- البيانات تحفظ محليًا في المتصفح فقط؛ لن يراها أي مستخدم آخر.
- الطلبات لا تُرسل إلى الموردين.
- لا تستخدمه في معاملات تجارية فعلية قبل إضافة خادم وقاعدة بيانات مشتركة، وتسجيل دخول، وصلاحيات، والتحقق من الموردين، وسياسة خصوصية وشروط استخدام ونسخ احتياطي وحماية مناسبة.
- تصدير APK أصلي ليس متاحًا من هذه الملفات وحدها؛ يمكن أولًا تجربة PWA ثم تغليف المشروع كتطبيق Android بعد اختبار الاستضافة والوظائف.
